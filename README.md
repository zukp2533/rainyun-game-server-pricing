## “一键”省掉的到底是哪几步

MCSM 是一套开源、分布式的游戏服务器控制面板，支持 Minecraft 和 Steam 游戏服务器，能集中管理多台机器、支持多用户权限。雨云把它内置进游戏云之后，服务端程序、启动参数、端口配置这些原本要在命令行里敲的东西，变成了面板里的下拉框和按钮。

用面板服，你要做的是：控制台 →「云产品」→「游戏云」→ 选 MCSM 面板 → 在游戏列表里选游戏 → 下单 →「管理」→「进入 MCSM 管理面板」→ 一键开启实例。全程不碰 SSH。

用 VPS，你要做的是：连 SSH、装 JDK、上传服务端 jar、写启动命令、开放端口、处理防火墙。自由度大，门槛也实实在在。第一次开服的人选面板，省下的不是钱，是一晚上的搜索时间。

面板的一键列表覆盖 Minecraft Java 版、基岩版、泰拉瑞亚、饥荒、幻兽帕鲁。Valheim 不在里面，得走 VPS 自己用 SteamCMD 装。

## MC 面板服开服：卡住的地方通常在端口

MC 的流程是选机型下单 → 进控制台 → 在 MCSM 面板里选服务端类型（Paper / Spigot / Forge / Fabric）→ 设端口 → 一键启动 → 把 IP 加端口发给朋友。

两处容易出问题。

一是 NAT 模式。雨云默认给共享 IP，可以开 15 个端口转发，纯 MC 服完全够用；要独立公网 IP 得加钱升级。NAT 模式下 25565 端口不会自动生效，得在面板里手动转发一次，否则朋友连不上，你自己用内网地址却能进。

二是 eula.txt。首次启动大概率会在控制台看到 `You need to agree to the EULA in order to run the server`，去文件管理里把 `eula.txt` 的 `false` 改成 `true`，保存后重新开启，等到控制台出现 `Done` 才算真正启动完成。

# -Xmx4G` 的注释去掉并改成实际内存，再把启动命令换成 `bash run.sh`。另一个是 Mohist，目前只更新到 1.20.2（mohist-1.20.2-165），想模组和插件同开又非要 1.21 的人，这条路线走不通。

## 饥荒一键开服：多了一个 Klei Token

饥荒的流程比 MC 多一步授权。选游戏、下单、进面板、一键开启实例这几步一样，但实例起来之后，你得去 Klei 官网登录账号，在「游戏服务器」页面生成一个专用 Token，粘贴进面板配置，再填服务器名、密码、最大玩家数。

Token 没填，服务器起得来但搜不到。填完之后，在饥荒游戏里选「在线」→「搜索服务器」，或者直接用 IP 加端口直连。

关于耗时，官方口径是“三分钟就能开起来一台饥荒专属服”，这指的是从购买到实例启动；从购买到真正进游戏，熟练了 15 分钟以内。两个数字不矛盾，说的是不同阶段。

## 配置怎么选：饥荒看核心数，MC 看单核主频

饥荒的配置逻辑很直接：它是单核游戏，每个世界（地面或洞穴）只用一个 CPU 核心，每多一层世界就多占一个核。所以地面加洞穴的主流玩法是 2 核起步，多世界才需要 4 核。

内存这条线更硬。2G 只够跑少量小 MOD，一旦加上“永不妥协”“棱镜勋章”这类大型主题 MOD，会直接爆内存卡死。4G 才是舒服的起步线。

- 纯地面、6 人以下、少 MOD → 1核2G，能跑，内存紧
- 地面 + 洞穴（主流）→ **2核4G**
- 地面 + 洞穴 + 大型 MOD → 2核4G 到 4核8G
- 多世界 / 多层地图 → 4核8G

MC 这边看的是单核性能。1.18 之后版本对单核的要求明显拉高，拿 2.9GHz 的老至强开模组服，TPS 掉到 15 都不算严重。按机型分档大致是这样：

- i9-14900K / 14900KF（6.0GHz）：1.20+ 大型模组整合包、50 人起群组服
- Ryzen 7950X / 9950X（5.7GHz）：高版本插件加模组混开
- R9 5900X（4.8GHz）：中高版本模组、小型群组、基岩版轻量服
- Gold 6146（4.2GHz）：纯净插件服够用
- Platinum 8275cl / 8259cl（3.9GHz）：低版本模组或高版本纯净插件，有积分兑换的免费档
- E5 2666v3：超低预算挂机服、低版本小型生存，同样有免费档

这里有个说法上的差异要提醒：第三方开服教程建议 MC 高版本 Java 服“4核8G 起，不低于 4核8G”，而雨云面板服主推 2核4G。两者针对的场景不同——教程假设的是带模组整合包、十几人同时在线的服；2核4G 面板服跑的是几个人玩的纯净或轻模组生存。你按自己的实际人数和 MOD 量对号入座，别拿教程的上限去否掉一个够用的下限，也别拿面板的入门档硬扛一个 40 人的整合包服。

## 什么情况下不该选雨云

三种情况可以直接排除。

需要 99.99% SLA 的商业级服务器，雨云的定位是性价比，不是高端商用，这类需求找大厂更稳妥。想开 Valheim 又不想折腾命令行的，面板一键列表里没有它，只能走 VPS 自己装。非要 1.21 的 Mohist（模组+插件同开），版本停在 1.20.2，等不到。

还有一种：偶尔玩一次，一个月开不了两回。这种情况按天付费或用完就退更划算，长期套餐对你是浪费。

拿阿里云做个客观对照：它基于计算巢服务，镜像里集成了 MC 服务器程序，一键购买及部署，约 1 分钟创建完成，不用手动部署。目前在售两款，4核16G / 10M 固定带宽 / 100G 系统盘 89 元/月，8核32G / 10M / 100G 160 元/月，可选 1 个月到一年，但只有 1 个月和 3 个月档有活动，更长时长价格偏高。游戏参数可以全部用默认值（生存模式、难度 easy、最大玩家数 20、视距 10、模拟距离 10），也能逐项自定义。

两边的差别在形态上：阿里云是一体化托管、按月计费、档位少而大，适合不想碰任何配置、预算宽松的人；雨云是面板自助、支持日付和动态计费、机型从入门到 9950X 铺得很开，适合按需挑档、预算几十块的人。
